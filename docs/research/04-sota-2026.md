## Context: Minecraft versioning in 2026
Java Edition dropped the 1.x scheme after 1.21.11 (9 Dec 2025). New format YY.D.H: 26.1 "Tiny Takeover" (24 Mar 2026),
26.2 "Chaos Cubed" (16 Jun 2026), 26.3 "Wilderness Bound" (15 Sep 2026, protocol 777); 26.4 snapshots are live. No 1.22.

## A. Bot frameworks ("body")

### Mineflayer (PrismarineJS) — still the default body, but lagging the game by ~2 drops
- npm latest **4.39.0 (2026-09-06)**; 7.4k ★, MIT. Supported: 1.8.8 … 1.21.11, **26.1** (latestSupportedVersion).
  node-minecraft-protocol 1.68.0 also tops out at 26.1.
- **26.2 is NOT supported yet**: issue #3932 / #3893, PR #3926, branch `pc26_2` / PR #3958 (new `attack` packet, 26.x
  `use_entity`, `clockUpdates[]`, `player_loaded`) needs minecraft-data `pc_26_2` (#1216), prismarine-chunk #331,
  prismarine-physics #138. 26.3: nothing. Maintainers slow to review.
- Workaround used by everyone (Mindcraft, azalea): server on 1.21.x or ViaProxy/ViaVersion in front.
- Python: JSPyBridge (`pip install javascript`); no native Python framework.

### Azalea (Rust, azalea-rs/azalea) — tracks the game faster, less ecosystem

## B. LLM / learned Minecraft agents (open source)

**Mindcraft** (mindcraft-bots/mindcraft, 5.9k ★, MIT). Node 18/20; MC ≤1.21.11 (1.21.6 recommended), ViaProxy otherwise.
`Agent` orchestrates a Mineflayer bot + plugins, `Prompter` (17 providers; separate `model`/`code_model`/`vision_model`/
`embedding`/`speak_model`), `History` (every 5 turns summarized into a ≤500-char memory `bots/<name>/memory.json`),
`ActionManager` (~40 `!commands`: `!goToPlayer`, `!collectBlocks`, `!craftRecipe`, `!smeltItem`, `!placeHere`, `!attack`,
`!goal`, `!startConversation`, `!digDown`, `!useOn`… + 14 queries), `Coder` (`!newAction`: LLM writes JS against
`skills.js` (2,093 lines), sandboxed only if `allow_insecure_coding`), `SelfPrompter` (autonomous `!goal` loop), `modes.js`
(reflexes: self-preservation, hunting, item collecting, torch placing, idle staring), `NPCController` with `BuildGoal` +
JSON construction templates, `Camera`/`VisionInterpreter`, `speak.js` (TTS; **no STT**), `MindServer` (socket.io hub + web
UI :8080). MineCollab benchmark (arXiv 2504.17950). Fork **mindcraft-ce** (141 ★): function calling, LanceDB RAG. Fine-tuned
local models **Andy-4** (8B) and **Andy-4.2** (Qwen3.5-9B base, full diamond armour unassisted; weak at building).

**Project Sid / PIANO (Altera)** — arXiv 2411.00114: 10 concurrent modules read/write a shared Agent State; Cognitive
Controller sees a bottlenecked view and broadcasts decisions so speech and action stay coherent; 10–1000+ agents. **Nothing
reusable public**.

**Odyssey** (zju-vipa, 409 ★, IJCAI 2025, MIT / dataset CC BY-NC-SA): Mineflayer skill library of 40 primitive + 183
compositional skills, MineMA = LLaMA-3 fine-tuned on 390k wiki QA.

**Voyager** (7.2k ★, MIT): frozen 2023, still the reference for code-as-skills.

**CraftJarvis (PKU) pixel-based stack** — all MineRL-1.16.5 (keyboard/mouse, raw frames) via **MineStudio** (MIT): VPT,
STEVE-1, GROOT, ROCKET-1/2/3, JARVIS-1, JARVIS-VLA (ActVLP, 1k atomic tasks), **OpenHA** (Jun 2026, MIT, Qwen2-VL-7B
checkpoints + ~4.2B tokens of action datasets — the most reusable open VLA weights), MC-Planner/DEPS (dead), GITM (paper
only), MP5, Steve-Eye (dead), LARM (no code), Optimus-1/2/**3** (dual-router MoE over Qwen2.5-VL, MIT), Plancraft (pip),
MineDojo (unmaintained).

**World models** (imagination/planning research, not a body): MineWorld (microsoft, MIT, checkpoints taken down), Oasis 500M
(etched-ai/open-oasis, MIT), Lucid v1, Matrix-Game 2.0 (Skywork), **Dreamer 4** (Sep 2025: diamonds from offline data only;
no official code; community next-state/open-dreamer).

**Headline 2026 result**: Google DeepMind, arXiv 2610.22319 (15 Oct 2026) — four Gemini 4 Argon agents beat Minecraft from
random spawn, Easy, MC 1.20.4, in 27h14m, 2,783 self-written JS programs via Mineflayer (each program = async fn with
pathfinder, 60 s timeout, median 33.5 s, globals persist, no process/file access), **text observations only (no pixels)**,
private + shared persistent memory, in-game chat for coordination, context compaction, 605 deaths, 22 % program error rate,
~$520. No code released. Admitted limitations: code-level perception "sees through rock", Easy difficulty, single run.

## D. In-game voice
- **Simple Voice Chat** (henkelmax, 78M downloads, current to 26.3): Plugin API `createEntityAudioChannel`,
  `createLocationalAudioChannel`, `createAudioPlayer(channel, encoder, short[] 48 kHz PCM, 960-sample frames)`,
  `createAudioSender(connection)` (simulate a player's mic — only for players WITHOUT the mod, i.e. perfect for a Mineflayer
  bot account), Opus encoder/decoder, events `MicrophonePacketEvent` (server-side mic packets → PCM → STT),
  `PlayerConnectedEvent`.
- Pure-Mineflayer bridges: forester302/mineflayer-simple-voice-chat (fragile), mineflayer-plasmovoice. Robust route: a
  server-side SVC plugin bridging audio to the agent over WebSocket. Existing bridges of that shape: Easy LLM Voice (Fabric
  1.21, ARR), SVC Player Voice Recorder (server-side Paper plugin). STT/TTS: client-side Whisper mods, Kokoro TTS, OpenAI/
  Google TTS, espeak. **Nobody has shipped STT→LLM→TTS→SVC for a Mineflayer bot end to end.**

## Recommendations for a new agent

**Body**: Mineflayer 4.39 on a **1.21.11 server** (or 26.1) today; for 26.2+/26.3 ViaProxy in front. Keep the body behind a
thin "BodyAPI" so it can be swapped to azalea or a server-side Fabric/Baritone body later. Plugins: pathfinder 2.4.5 as
baseline but evaluate `@miner-org/mineflayer-baritone`, collectblock, auto-eat 5.x, armor-manager, tool,
`@nxg-org/mineflayer-physics-util`; replace pvp 1.3.2 with an own tick loop. Perception: structured state primary +
headless JPEG snapshots for a VLM only when symbolic data is insufficient. Don't go pixel-only: every pixel stack is locked
to MineRL 1.16.5.

**Ideas worth adopting**: (1) DeepMind-style "programs as actions" + Voyager/Odyssey skill library with success records;
(2) PIANO-style concurrency: tick-rate reflex loop that preempts the LLM, slow planner behind an information bottleneck,
separate talking module; (3) mc_aiplayer/cairn discipline: validated tools from a frozen vocabulary, deterministic executors
with typed postconditions, cost caps, snapshots; (4) two-tier memory: private + team-shared notes with coordinates plus LLM
summarization, later knowledge graph + experience pool; (5) multi-agent via in-game chat + shared memory + leader election;
(6) local model for cheap reflex-level chat, frontier model for planning; (7) evaluate on MineCollab + TeamCraft +
MC-EvoBench-style transfer probes.

**Gaps nobody has filled**: a Mineflayer body current with 26.2/26.3; an end-to-end voice loop; autonomous *creative*
building beyond templates; genuine self-improvement (transfer); **human-fair perception** (DeepMind's agents "see through
rock"); long-horizon survival on Normal/Hard with hunger; any open implementation of PIANO at scale; a maintained
Python-native body. A project that ships a 26.x-current body + voice + verifiable skill-transfer evaluation would be ahead
of everything public.
